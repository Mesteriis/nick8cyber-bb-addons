# hide-dispatched

Плагин скрывает из сайдбара служебные треды (`visibility: hidden`). Работает независимо от orchestrator — и в тредах «Без плагина» (orchestrator §19.3).

## 1. Что скрывается

1. **Тред с родителем** (`parentThreadId` не пуст) — всегда, кто бы его ни создал: команда плагина, `bb thread spawn --parent-*`, `bb tasks dispatch`, SDK другого плагина. Причина: BB наследует дочернему треду видимость родителя, у видимого координатора дочерний тред видим (факт SDK 0.6.x: «a child inherits its parent»).
2. **Тред от отслеживаемого плагина** (`originPluginId` из списка `tracked`, по умолчанию `["tasks"]`) — как в r1.
3. **Тред без родителя, созданный из CLI или окна, — не скрывается:** это может быть тред человека. Отличить агента от человека по данным BB нельзя (`origin = cli`, `senderThreadId = null` у обоих).

## 2. Когда

- Событие `thread.created` — сразу.
- Событие `thread.active` (первый ход) — повторная проверка: родителя могли назначить после создания (`bb thread update --parent-thread`). Событий на смену родителя в SDK нет.
- **Один раз на тред:** скрытый плагином или уже рассмотренный тред запоминается (`kv`, множество id с обрезкой старше 30 дней). Если человек потом сделал тред видимым — плагин его больше не трогает.
- Ошибка `threads.update` — в журнал, создание треда не ломается; повтор — на следующем `thread.active`, не чаще одного раза.

## 3. Настройки и CLI

- `hideChildren` — `true` по умолчанию; `false` возвращает поведение r1 (только `tracked`).
- `bb hide-dispatched status|on|off` — как в r1; `status` показывает и `hideChildren`.
- `bb hide-dispatched sweep [--dry-run]` — скрывает видимые неархивные треды по правилам §1 (с родителем или от `tracked`), уже рассмотренные по §2 не трогает.

## 4. Тесты

Поддельный SDK: тред с родителем от `cli`/`sdk`/`plugin` → скрыт; без родителя от `cli`/`app` → не тронут; родитель назначен позже → скрыт на `thread.active`; человек открыл тред → второй раз не скрывается; `hideChildren = false` → только `tracked`; ошибка `update` → журнал, без исключения наружу.
